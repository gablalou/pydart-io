<objective>
Refine the write slice from Plan 01 into a fully configurable writer: the user chooses the
compression codec (snappy/zstd/gzip/uncompressed) and the row-group size (row count) on
`to_parquet` (PARQ-02, PARQ-03). Plan 01 wrote with the crate-default (snappy) `WriterProperties`;
this plan replaces that `None` with an explicitly-built `WriterProperties` and validates the codec
string against the exact four D-29 codecs, rejecting anything else with a named `FlintError`.

After this task, a user can do something they could not after Plan 01: pick zstd/gzip/uncompressed
and control row-group granularity — while a typo'd codec fails loudly instead of silently writing snappy.

Purpose: complete PARQ-02 (codec choice) and PARQ-03 (row-group sizing) with honest rejection of
unsupported inputs.
Output: `build_writer_properties` in parquet_io.rs, extended `to_parquet` signature, a new
`FlintError::UnsupportedCodec` variant, and a Python compression/row-group test.
</objective>
