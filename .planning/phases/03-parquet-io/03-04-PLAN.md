tz-aware timestamps and categorical/dictionary encoding), the D-31/WR-01 nullability bug fix that
PARQ-06 schema fidelity depends on, and D-21 (multi-file/directory read into one Table, extending PARQ-01).

signal — writing those tests against the known-broken `build_field` (which derives nullability from

path for the real Phase-2 dtypes.

exact fidelity, and read a directory or list of Parquet files as a single Table.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| pandas source dtype nullability -> build_field | A column's declared nullability drives the emitted Arrow/Parquet schema; deriving it wrongly corrupts downstream schema merges. |
| directory / file-list path args -> from_parquet | Untrusted directory contents and path lists drive which files are opened and concatenated. |
| Parquet file bytes (multiple files) -> read_parquet | Each file is untrusted; a corrupt or schema-divergent file must fail loud, not silently merge/skip. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-06 | Tampering (silent schema corruption) | build_field nullability (WR-01) | high | mitigate | Nullability sourced from the declared source dtype schema, not observed null_count — prevents a wrongly-non-nullable field silently breaking downstream concat/merge (the 02-REVIEW.md WR-01 failure). Verified by an explicit concat_tables reproduction test (ASVS V5). |
| T-03-07 | Tampering (unintended data inclusion) | directory read file selection (D-21) | medium | mitigate | Directory reads filter strictly to .parquet, sorted deterministically; a non-Parquet file passed explicitly or a parse failure raises a named FlintError (ParquetReadError) — never silent inclusion-as-garbage or silent skip (RESEARCH Security Domain). |
| T-03-08 | Tampering (silent wrong merge) | cross-file schema reconciliation (D-21) | medium | mitigate | Strict schema-equality across files; first mismatch raises ParquetSchemaMismatch naming file + column, never a silent best-effort union that could misalign columns. |
| T-03-02 | Information Disclosure | caller-supplied path (traversal) | low | accept | Out of scope per D-20 (same trust level as Python open()); caller responsibility. Path traversal is canon security — covered by /gsd-secure-phase, not minted as a phase prohibition. |
| T-03-SC | Tampering | cargo package install | high | accept | No new dependency in this plan (parquet 59.1.0 added + audited OK in Plan 01). No new supply-chain surface. |
</threat_model>
