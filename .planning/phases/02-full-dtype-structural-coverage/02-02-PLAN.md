<objective>
Deliver CONV-04 (object/string) as a vertical slice: classify -> validate -> convert -> round-trip,
in both directions, for both the ArrowDtype string path and the legacy numpy object-dtype path.

Behavior delivered:
- string[pyarrow] columns round-trip zero-copy with correct values + None handling (D-10).
- numpy object-dtype columns of Python str (with None) round-trip via an honest copy, reported as
  zero_copy=false with a specific reason (D-10).
- object-dtype columns containing any non-str value are rejected with a clear flint.FlintError
  naming the column and the offending value's type, via a Flint-owned validation pass that runs
  before any conversion is attempted (D-11 / RESEARCH Pitfall 2).

Purpose: complete the string story, which pyarrow's permissive inference does NOT make safe for
free -- the validation pass is the genuinely new code here; the conversion mechanics reuse the
existing generic `__arrow_c_stream__` fallback (RESEARCH "Don't Hand-Roll").
Output: ArrowKind::String + plan_column arms, classify_dtype string branches, a new
validate_object_column_contents function, and a Python object/string test file.
</objective>
