<objective>
Deliver CONV-05 (categorical) as a vertical slice with full round-trip fidelity: classify -> convert
-> reconstruct -> round-trip, preserving the ordered flag, exact category order, and exact code
width.

Behavior delivered:
- A pandas Categorical (ordered or unordered) round-trips as a real pd.Categorical with identical
  ordered flag, categories (order included), and codes dtype (D-17 / D-18).

This slice fixes TWO distinct, empirically-verified metadata-loss bugs that both violate D-17:
- Pitfall 3: from_pandas rebuilds each Field from array.data_type().clone(), silently dropping the
  dictionary ordered flag (which lives on Field, not DataType). Fixed via Field::new_dictionary +
  with_dict_is_ordered for Dictionary columns.
- Pitfall 4: to_pandas's blanket types_mapper=pandas.ArrowDtype reconstructs a dictionary column as
  an ArrowDtype dictionary, not a real Categorical. Fixed via a per-column-type-aware types_mapper
  that returns None for dictionary types.

Purpose: categorical fidelity is the project's precision-over-convenience posture made concrete;
the conversion mechanics are already generic (RESEARCH Pitfall 0 confirmed code-width/order survive
the FFI import), so the work is entirely in the surrounding Field/type-mapper reconstruction.
Output: DtypeBackend::Categorical + ArrowKind::Categorical, classify_dtype categorical branch,
the two reconstruction fixes, and a fidelity test file.
</objective>
